## Run locally

Extract the full ZIP to a normal writable folder. On Windows, double-click START_REVIEW3.bat and choose Prepare, then launch the same menu and choose Launch. Prepare requires Python 3.12 available through the Windows Python launcher and internet for dependencies/embedding weights. Node.js LTS is needed to rebuild source; the supplied compiled frontend can run without Node. First launch prompts for one local account and creates a local random JWT secret. No Gemini key is needed for the two narrow verified-policy demonstrations; other generated answers require a locally configured Gemini key. Never paste credentials into review files.

Other menu options: Test, Preflight, Development, Screen, Freeze, Frozen, FrozenAnswers and Report. Freeze/Frozen refuse incomplete independent approvals. Nothing retrains the classifier or rebuilds the database. The script does not change PowerShell execution policy; if your machine blocks scripts, ask your administrator for the permitted local execution route. The Python workflow was exercised here on Linux; Windows-specific installation/execution still needs local acceptance.
