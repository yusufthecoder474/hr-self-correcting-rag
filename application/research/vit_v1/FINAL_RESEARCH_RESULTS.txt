6. KEY FINDING

The learned halting policy reduced the average number of
retrieval attempts compared with the Fixed-3 baseline while
maintaining the same critic-defined retrieval success rate
on the 23-question VIT evaluation set.

7. LIMITATIONS

The evaluation set contains only 23 questions.

Critic-defined success is based on the local critic threshold
and is not equivalent to answer-level accuracy.

Only six flagged cases were manually validated.

Some retrieved contexts contain unrelated neighboring policy
text, particularly for some maternity and multi-section queries.

The Gemini answer-generation service was not consistently
available during testing, so local policy fallback was used
for some responses.

8. CONCLUSION

The current implementation demonstrates adaptive retrieval
with learned halting on a real VIT HR policy corpus. The
learned policy reduced retrieval effort while preserving the
same critic-defined success rate as the Fixed-3 baseline.
Further evaluation with a larger question set and independent
human ground truth is required for stronger claims about
answer accuracy.
