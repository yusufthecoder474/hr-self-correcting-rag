HR SELF-CORRECTING RAG ASSISTANT
================================

PROJECT OVERVIEW
----------------
A retrieval-augmented HR policy assistant with:
1. Semantic retrieval using SentenceTransformers.
2. ChromaDB vector storage.
3. Local retrieval critic.
4. Query rewriting for self-correction.
5. Learned STOP/CONTINUE halting policy.
6. FastAPI backend.
7. Browser-based frontend.
8. Gemini-based answer generation with local fallback.

MODEL / RETRIEVAL

RESULT
------
The system demonstrates:
weak retrieval
-> learned CONTINUE
-> query rewriting
-> improved retrieval
-> learned STOP

IMPORTANT LIMITATIONS
---------------------
1. The halting dataset is relatively small.
2. STOP and CONTINUE classes are imbalanced.
3. The learned policy has only preliminary generalization performance.
4. Current efficiency measurements use local critic/rewriter proxy calls.
5. Gemini answer generation may be limited by free-tier quota.
6. The 8.11% reduction is a proxy workload reduction, not a measured
   billing-cost reduction.
